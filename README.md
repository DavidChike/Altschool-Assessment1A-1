# AltSchool Assessment 1A

A simple multi-page HTML project built for the **AltSchool Africa — School of Engineering (Karatu 2026)** assessment. It contains a personal profile home page and an application form page, written in semantic HTML.

## Pages

- **`index.html`** — Home page with basic profile information, biography, "Why AltSchool", and goals.
- **`Form.html`** — Application form with personal information, account information, and program sections.

## Tech Stack

- HTML5 (semantic elements, forms, and accessibility attributes)

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/NdulueMarvellous/Altschool-Assessment1A.git
   ```
2. Open `index.html` in any web browser.

No build tools or dependencies required.
